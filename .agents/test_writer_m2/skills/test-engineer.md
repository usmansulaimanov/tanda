# Test Engineer Skill
Source: /Users/usman/.gemini/config/skills/test-engineer/SKILL.md

Core Methodology:
1. Analyze Before Writing: Public API, edge cases, error paths, existing patterns.
2. Test at the Right Level: Integration tests for crossing boundaries (controllers, security filter chain, repositories).
3. Cover Happy path, Empty input, Boundary values, Error paths, Concurrency.
4. Independent tests with clean setup/teardown.
5. Descriptive test naming reflecting specification.
