# ADR-003: Dual Route Mapping Parity (`/api/...` and `/api/v1/...`)

## Status
Accepted

## Context
Жобада клиенттер мен ескі скрипттер кейде `/api/...`, ал кейде `/api/v1/...` маршруттарын қолданады. Бұл SecurityConfig және Controller деңгейінде сәйкессіздіктер тудыруы мүмкін.

## Decision
Барлық эндпоинттер екі префикс үшін де толық паритетте жұмыс істейді:
1. `SecurityConfig` ережелері екі префиксті де қамтиды:
   - `/api/auth/**` және `/api/v1/auth/**`
   - `/api/books/**` және `/api/v1/books/**`
   - `/api/admin/**` және `/api/v1/admin/**`
2. Контроллерлер `@RequestMapping({"/api/...", "/api/v1/..."})` форматында жарияланады.
3. `SecurityRbacMatrixIntegrationTest` тест матрицасы арқылы екі префикс бойынша да рұқсаттар толық тексерілген.

## Consequences
- Ескі және жаңа клиенттер үшін 100% кері үйлесімділік.
- Қауіпсіздік тесіктері жойылған.
