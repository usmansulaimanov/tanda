# ADR-001: Stateless JWT Authentication via HMAC-SHA256

## Status
Accepted

## Context
Платформа Tanda талап етеді:
- Жедел және масштабталатын авторизация (Web + болашақ Mobile қосымшалар).
- Серверлік сессиялар немесе Redis кэшінсіз жеңіл бэкенд (KISS принципі).
- Рөлдік басқару (RBAC): `admin` және `client`.

## Decision
Біз **Stateless JWT (JSON Web Tokens)** стандартын таңдадық (`jjwt` 0.12.5 кітапханасы арқылы):
1. **HMAC-SHA256 (HS256)** алгоритмімен қол қойылады. Кілт ұзындығы 256 биттен кем болмауы керек (Padding механизмі қарастырылған).
2. Токен payload-та `userId`, `email`, `role`, `idNumber` өрістерін сақтайды.
3. Әрбір HTTP сұраныс `JwtAuthFilter` арқылы `Authorization: Bearer <token>` тақырыбын тексереді.
4. Құпиясөздер **BCrypt** (strength 10) арқылы хэштеледі.

## Consequences
### Positive
- Сервер жадында (RAM/Redis) сессия сақтау қажет емес — бэкенд 100% stateless.
- Горизонталды масштабтау қарапайым: кез келген бэкенд инстансы бірдей құпия кілтпен токенді математикалық түрде тексере алады.
- Жылдам жұмыс істейді (токенді тексеру 0.1 мс алады).

### Negative / Trade-offs
- Токен мерзімі аяқталғанға дейін оны сервер жағынан бірден қайтарып алу (immediate revocation) үшін Blacklist механизмі қажет (болашаққа қалдырылды).
